# RAG Model

The RAG has many elements to it. Specific "modules" that are found through papers will be explained and cited here.

## Files

- [ingestion.py](./ingestion.py): handles indexing the repos into the database.
- [splitters.py](./splitters.py): handles splitting/chunking files based on their file type.
- [query.py](./query.py): handles querying the RAG.
